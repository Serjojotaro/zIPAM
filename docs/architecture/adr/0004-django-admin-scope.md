# ADR-0004: Django Admin — только отладка

- Status: accepted (2026-10-06)

## Context
В ETIA Django Admin — «источник правды». Для zIPAM основной интерфейс —
React (спека §21).

## Decision
django.contrib.admin остаётся включённым, но доступен только superuser'у и
рассматривается как инструмент диагностики, не пользовательский интерфейс.
Изменения доменных объектов пользователями — только через API+UI с permissions (§19).

## Consequences
- (+) быстрый путь к данным при отладке;
- (–) admin не должен становиться зоной обхода валидации сервиса — правки
  через него не выполняли business-правила; при росте ценности данных
  рассмотреть read-only admin.
