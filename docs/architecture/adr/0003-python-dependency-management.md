# ADR-0003: Зависимости Python — requirements.txt; uv — только как менеджер Python

- Status: accepted (2026-10-06)

## Context
ETIA (смежный проект команды) живёт на requirements.txt; единообразие удешевляет
онбординг. uv/poetry дают блокировки и воспроизводимость, но вводят второй
инструментальный стек.

## Decision
requirements.txt / requirements-dev.txt с разумными диапазонами. Версию Python
3.12+ ставит и держит uv (`uv python install 3.12`), venv — обычный.
Воспроизводимость сборок в CI обеспечивает кэш pip + фиксация Docker-базовых
образов; release-таргеты собираются в Docker.

## Consequences
- (+) единый стиль зависимостей с ETIA;
- (–) полных лок-файлов нет — риск дрейфа зависимостей между окружениями
  снижается Docker-сборками; при росте проекта пересмотреть (переход дёшев).
